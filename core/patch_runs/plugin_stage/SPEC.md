# SPEC каталога `core/patch_runs/plugin_stage/`

Здесь лежат JSON-пакеты plugin-stage, разложенные по timestamp/process-id. Каждая вложенная папка — отдельный снимок набора patch id. Файлы не импортируются Flask и не являются Python-плагинами.

| Папка | Содержание |
|---|---|
| `20261021_112607_31591/` | Набор JSON-патчей 1.0.10, 1.0.12, 1.0.21–1.0.26. |
| `20261022_161532_22883/` | Такой же набор, отдельный запуск/снимок. |
| `20261022_161631_28003/` | Такой же набор, отдельный запуск/снимок. |
