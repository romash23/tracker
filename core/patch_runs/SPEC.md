# SPEC каталога `core/patch_runs/`

Каталог хранит артефакты стадий применения plugin/client-патчей. Это не каталог исходников приложения и не runtime-папка для произвольных скриптов.

| Элемент | Назначение |
|---|---|
| `plugin_stage/` | Снимки JSON-патчей, сгруппированные по времени запуска и идентификатору процесса. |
| `SPEC.md` | Эта инструкция. |

JSON внутри подпапок нужно рассматривать как историю/пакет операций patcher. Применение выполняет `core/patcher.py`; не редактируйте уже применённые артефакты без проверки `.patches_applied.json`, резервной копии и dry-run.

См. [../SPEC.md](../SPEC.md) и [plugin_stage/SPEC.md](plugin_stage/SPEC.md).
