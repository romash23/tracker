Новая задача

Новая строка сохраняется с датой: «10.11.2026 — скинуть первый драфт». Последняя запись видна в колонке «Комментарий».
Тип (Приказ / Распоряжение / СЗ / Другое), описание и путь к файлу на общем ресурсе или ссылка. Сам файл не загружается.
Период может прерываться, например 10.11–22.11 + 01.12–20.12. Вне периодов нагрузки нет.
Задаётся пользователем, на этапы не делится. Для доп. задачи в проверке добавляется каждому выбранному банку проверки, для остальных — назначенным сотрудникам.
Список открытых карманов выбранного направления. Новые карманы задаются в «Планирование → 🗂 Карманы».
Указывается только дата начала этапа. Конец подтягивается автоматически (начало следующего этапа − 1 день); у последнего этапа — дедлайн задачи. Можно задать конец вручную — тогда начало следующего не трогается.
